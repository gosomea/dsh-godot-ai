# Godot Creator workspace brand specification

## Assets

- `assets/godot/icon-color.svg`: official Godot Engine colored icon from `https://godotengine.org/assets/press/icon_color.svg`.
- The icon represents Godot Engine, not dsh-godot-ai or an endorsement.
- Source and usage guidance: `https://godotengine.org/press/`.
- License: Creative Commons Attribution 4.0 International; attribution is recorded in `THIRD_PARTY_NOTICES.md`.

## Tokens

- Creator accent: `#478CBF` (official Godot blue sampled from the official icon).
- Accent strong: derive with `color-mix()` against the current DSH primary label; do not introduce another brand hue.
- Surfaces, labels, borders, state colors and fonts: inherit current DSH alias tokens.
- Spacing: 4px base; 8/12/16/24px primary steps.
- Radius: 8px controls, 12px facts, 14px sections, 18px drawer top corners on narrow viewports.
- Motion: 160ms ease-out; disabled under reduced motion.

## Usage

- Use the official icon only in the Creator header and workspace drawer.
- Preserve aspect ratio; never recolor, distort or redraw it.
- Godot blue remains an emphasis color, not a full-page background.
